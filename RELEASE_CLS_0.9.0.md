# LMSPilot CLS 0.9.0 — Astral Academy V3 release candidate

0.9.0 là bản tái thiết kế toàn diện portal, không phải bản đổi màu hoặc chỉnh nhẹ layout. Astral Academy V3 thay mới shell, hierarchy, không gian thị giác, responsive behavior và trải nghiệm các trang cốt lõi trong khi giữ nguyên API, permission và dữ liệu nghiệp vụ thật.

Điểm chính:

- Shell nổi, navigation phân nhóm, contextual top bar và trạng thái realm.
- Command Atlas `Ctrl/Cmd + K` tìm route thật và lọc theo quyền người dùng.
- Login, dashboard, khóa học, lớp học, hành trình học, kỳ thi và đổi mật khẩu được dựng lại hoàn toàn.
- Header thiên thể và design system mới phủ các detail/workspace/admin console.
- CSS/SVG self-contained; dynamic branding, responsive, high contrast và reduced motion.
- 8 UI regression test mới; tổng 104 test, TypeScript semantic check, production build và npm audit đều đạt.

Đây vẫn là **full-source release candidate**. Xem `docs/UI_UX_REDESIGN_0.9.0.md`, `docs/BUILD_VERIFICATION_0.9.0.md` và `DELIVERY_STATUS.md` trước khi nghiệm thu.
