# LMSPilot 0.18.0 — Readability patch

This package restores the 0.18 workspace/layout and applies a focused typography patch:

- removes right chevrons from the primary sidebar menu;
- keeps navigation labels on one line;
- hides redundant sidebar group headings;
- raises small supporting text by roughly 1–2 px;
- raises table, badge, organization-tree, member and integration microcopy;
- keeps the existing 0.18 feature logic, routes and backend unchanged.

The internal version remains `0.18.0` so existing manifests and verification tests stay valid.
